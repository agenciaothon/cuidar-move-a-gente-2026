# Cuidar Move a Gente — Outubro Rosa 2026

Apresentação da campanha à Rede Feminina de Combate ao Câncer de Três Lagoas, MS.

Iniciativa da Trok Car Brasil com 14 empresas parceiras.

## Apresentação

Abra `index.html` no navegador. O arquivo contém as imagens e funciona sem conexão à internet.

- Setas para a esquerda e para a direita: navegar entre as 11 telas.
- Home e End: ir para a primeira e para a última tela.
- Botão “Tela cheia” ou tecla F: solicitar tela cheia, conforme suporte do navegador.
- Botão “Animações”: ativar ou reduzir os movimentos.

A versão inclui o selo 3D da campanha e o logo da Trok em destaque.

## Publicação

Site estático preparado para o GitHub Pages a partir da raiz da branch `main`.

Para atualizar, substitua `index.html` pela versão revisada e envie um novo commit.
